## 四个业务场景

- [ ] 3.2 告警问题：检索已授权证据、展开引用、人工修改、确认并复制、记录人工已回复。
- [ ] 群聊知识：审核前不命中、审核发布后命中、撤销后检索与未发送草稿停止引用。
- [ ] 资讯去重：模拟 RSS A → B → B 的记录数为 2 → 3 → 3，缺失发布时间保持 null。
- [ ] 安全规则：未知版本澄清、同版本正式证据冲突转交、无依据拒绝编造、客服 A 不能查询客户 B 数据或来源。
