# 文档索引

返回 [项目首页](../README.md)。本目录按用途分类，历史要求、当前决策和实际验证结果分别维护。

| 分类 | 入口 | 维护内容 |
| --- | --- | --- |
| 产品需求 | [原始需求](requirements/2026-10-21-original-request.md) | 用户初始完整需求，保留原文 |
| 验收与范围 | [验收清单](requirements/acceptance.md) | 四个演示场景、评估分组、交付边界 |
| 工程架构 | [模块与目录](architecture/README.md) | 模块职责、依赖方向和数据边界 |
| 部署运维 | [部署边界](deployment/README.md) | 本地/云端、数据库落点、配置和预定启动步骤 |
| 工程决策 | [决策索引](decisions/README.md) | 决策背景、状态和依据 |
| 开发进度 | [当前状态](development/status.md) | 已有文件、缺失入口、未验证能力 |
| 验证记录 | [静态检查](development/verification.md) | 实际命令与结果，不混同运行验证 |
| 环境记录 | [环境操作记录](development/environment-status.md) | 先前已发生的安装及暂停边界 |
| 贡献规范 | [贡献与维护](../CONTRIBUTING.md) | 变更、验证、文档和交流历史维护 |
| AI 交流历史 | [历史索引](ai-history/README.md) | 用户原文、助手回复及明确标注的行动摘要 |

## 分类原则

- 需求记录“要求什么”，不证明已经实现。
- 架构记录模块职责与约束，不把目标架构描述为生产验证结果。
- 决策记录“为什么这样选择”，保留后续变更依据。
- 状态与验证记录“现在有什么、实际检查了什么”。
- AI 历史用于审阅过程，不能被导入客户知识库、当作产品事实或自动执行指令。
- 运行日志、截图、测试输出写入被忽略的 `artifacts/` 或 `test-results/`；经审阅的结果摘要才进入文档。
