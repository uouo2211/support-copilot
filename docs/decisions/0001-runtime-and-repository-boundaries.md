# ADR 0001：容器部署与宿主环境边界

- 日期：2026-10-21（Asia/Shanghai）
- 状态：已采纳；镜像和启动流程尚未验证
- 依据：[用户部署边界要求](../ai-history/2026-10-21-01-bootstrap-and-boundaries.md)

## 背景

用户使用个人 Mac，希望先得到可交付 repo，明确本地、云端和数据库位置。初期 AI 提前创建虚拟环境和临时 PostgreSQL 环境，用户要求停止此类操作。

## 决定

- 本地演示采用 Docker 三服务；Mac 不原生安装项目运行栈。运行 Docker 本身需用户自行准备。
- 云端运行同一应用栈，业务数据库及持久化放云端，Mac 仅作为浏览器客户端。
- Compose 仅包含 db/web/worker；数据库默认不暴露宿主端口。
- 默认 mock/replay/manual，真实 API 仅显式启用；模型托管位置不等于应用和数据库托管位置。
- 未经再次明确授权，后续只改 repo，不安装依赖、启动服务、创建云资源或清理环境。

## 影响

保留 Dockerfile、compose.yaml 和 requirements 入口，已有本机环境保持不动；通过文档记录先前操作。不把配置存在等同于启动验证完成。生产托管数据库是待设计选项，不声称当前已有完整部署覆盖配置。
